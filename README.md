# 日麻風位盤（Riichi Wind Board）

純前端的三麻／四麻桌上風位盤與計分工具。沒有後端，也不需要登入；狀態存在瀏覽器 `localStorage`。

## 已完成

- 三麻／四麻切換；預設四麻半莊
- 東風／半莊
- 玩家朝向式風位＋分數顯示
- 中央顯示局數、本場、供託
- 榮和／自摸：番符、滿貫、跳滿、倍滿、三倍滿、役滿、多倍役滿
- 三麻自摸損
- 三麻本場自摸每位支付者 +100（每本場總 +200）
- 切上滿貫
- 頭ハネ ON；OFF 時可輸入複數榮和，而且每位可填不同番符
- 數え役滿、複合役滿
- 立直 -1000、供託累積；流局後供託保留
- 流局聽牌／未聽牌 3000 點罰符
- 親和／親聽連莊，本場自動推進
- 所有狀態變更寫入 Log
- 上一步 Undo
- 設定 → 手動修改分數（同樣寫 Log、可 Undo）
- iOS Files 類型視覺與暗色模式

## 直接使用

專案已包含編譯後的 `dist/logic.js` 與 `dist/app.js`，所以可直接開啟 `index.html`。

若 Safari / Chrome 對本機檔案有限制，可以在專案資料夾執行：

```powershell
py -m http.server 8000
```

再開啟：

`http://127.0.0.1:8000`

## 修改 TypeScript

原始碼在 `src/`。安裝 TypeScript 後：

```powershell
npm install
npm run build
npm test
```

## 本版規則決策

- 四麻起始點數：25000
- 三麻起始點數：35000
- 預設半莊，可改東風
- 頭ハネ預設 ON
- 頭ハネ OFF：允許複數榮和
- 複數榮和時，每位和牌者各自向放銃者收取自己手牌的榮和點＋本場；桌上供託只給距離放銃者最近的和牌者
- 三麻自摸損固定 ON
- 三麻榮和每本場仍 +300；三麻自摸每位支付者 +100，因此每本場總 +200
- 不做飛び自動終局；允許負分繼續
- All Last 若親和牌或親流局聽牌會繼續連莊，直到親失去連莊條件才終局
